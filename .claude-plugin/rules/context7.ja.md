# Context7 MCP 使用ルール

## ライブラリ使用時

ライブラリやフレームワークの API を使用する際は、実装前に必ず Context7 MCP 経由で最新のドキュメントとコード例を取得する。古い使用パターンの記憶に基づいてコードを書くことを避け、常に最新の正しい使い方に基づいて実装する。

## 外部ツールの設定と構文

設定ファイル（tsconfig、vite.config、eslint など）やCLI ツールの構文を記述する際は、事前に Context7 MCP を使用して正しいオプションとフォーマットを確認する。推測に基づいて設定を書かない。

## エラー処理時

ライブラリやツールに起因するエラーが発生した場合、直ちに Context7 MCP で正しい使用方法を確認し、公式ドキュメントに基づいて修正する。古い Stack Overflow の回答や記憶に基づく推測での修正を避ける。
